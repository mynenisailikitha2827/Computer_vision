# Computer_vision
**CV_LAB4.ipynb** processes grayscale images using OpenCV, NumPy and Matplotlib to compare edge detection methods: Sobel-Gradient magnitudes (3x3 kernels). Prewitt- Custom convolution filtering (`cv2.filter2D`). Canny:-Multi-stage hysteresis (100, 200 limits).  Outputs a 2x2 grid plot comparing all results
